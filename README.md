# 🎓 IHK Exam Prep - Java Quiz App

An interactive, console-based Java application for exam preparation. This project was developed as a Minimum Viable Product (MVP) to apply my Core Java knowledge in a practical scenario.

## 💡 Motivation & Architecture Decisions
This project was specifically built to focus on clean code, object-oriented principles, and robust error handling, I intentionally avoided heavy frameworks like Spring Boot or a relational database.

Instead, the questions are read efficiently from a CSV file using a `BufferedReader`. This demonstrates the handling of file I/O (`try-with-resources`), data modeling, and encapsulation in pure Java.

## 🚀 Features
* **Interactive CLI Quiz:** Navigate through multiple-choice questions directly in the terminal.
* **Dynamic Data Source:** Questions and answers are flexibly loaded from `questions.csv`. Questions and answers are in German Language as the IHK exam is in German Language.
* **Input Validation:** Catches invalid user inputs (e.g., numbers outside the valid range).
* **Automated Testing:** Logic verification via JUnit 5 tests (including the use of `@TempDir` for file simulations).

## 🛠️ Tech Stack
* **Language:** Java (Core Java / JDK 25)
* **Testing:** JUnit 5
* **Data Storage:** CSV file
* **Dependencies:** No external libraries used for the main application
